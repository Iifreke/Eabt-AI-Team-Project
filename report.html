📋 Executive Summary

This report documents the full technical development, issues encountered, fixes applied, and architectural decisions made for the School AI Chatbot Platform serving Babcock University and Ahmadu Bello University (ABU). ✅ What Was Built — Full Feature List

Visitor-Facing Widget

💬

AI Chat (Maverick)

RAG-powered chatbot answers questions about admissions, fees, programmes, campus life from uploaded documents.

📋

Lead Capture Form

Name, email, phone collected before chat starts. Data synced to Supabase and Zoho CRM automatically.

🔄

Session Resume

Returning visitors with the same email+phone pick up their previous conversation exactly where they left off.

📎

File Attachments

Send images, PDFs, audio, video in chat. Files stored in Supabase Storage and shown inline.

🎤

Speech-to-Text

Mic button records voice, sends to OpenAI Whisper, transcription fills the message box automatically.

🧑‍💼

Human Escalation

Visitor can request a human agent. Admin is notified instantly. Agent can reply live from the dashboard.

🎫

Offline Tickets

When agents are offline, visitor submits a ticket. Email confirmation sent to visitor, notification sent to staff.

🌟

CSAT Rating

5-emoji rating after live chat. Scores tracked per agent and visible in the Overview dashboard.

🏫

Multi-School Picker

One widget serves both Babcock and ABU. Visitor selects their school first, then chats with school-specific AI.

📊

Today / Week / Month / All Time stats: total contacts, chats served, AI resolved, CSAT, open tickets, pending chats.

💬

Live Chats (Escalations)

Pending / In Progress / Ended filters. Serve button, tag editor, notes, shortcuts autocomplete (type /).

Contacts

Agents / RBAC

Invite agents by email with roles (Admin or Super Admin). Super Admins can manage team members.

Knowledge Base

⏳ Outstanding Item — File Upload Architecture

The core issue with file uploads is that Vercel serverless functions have a 4.5MB maximum request body limit. This means even the multipart parsing fix has a hard ceiling — any file over ~3MB will fail.

The correct production solution (currently being implemented) is Presigned Upload URLs: the browser asks the server for a temporary upload URL, then uploads the file directly to Supabase Storage, bypassing Vercel entirely. This removes the 4.5MB limit and is the industry-standard pattern used by Slack, Notion, and Dropbox.

CURRENT (broken): Browser → Vercel Function (4.5MB limit) → Supabase Storage

CORRECT (to implement):
Step 1: Browser → POST /api/chat/media {action: presign} → Vercel → returns {uploadUrl, publicUrl}
Step 2: Browser → PUT directly to Supabase Storage (no Vercel involved, no size limit)
Step 3: Browser sends message with publicUrl as attachment
This fix is a 2–3 hour implementation. It resolves uploads permanently and supports files of any size.

⚖️ Architecture Decision — Vercel vs Dedicated Backend

This was a key architectural question raised by the team. Here is the full analysis.

Vercel Serverless (Current)

FactorAssessment
Setup speedFastest
Auto-scalingAutomatic
Cold starts1–3s delay
Request timeout10s (60s on Pro)
File upload limit4.5MB hard cap
WebSocketsNot supported
Real-time chatPolling workaround
Monthly cost (500 users)$20/mo (Pro)

Railway / Render (Dedicated)

FactorAssessment
Setup speedModerate — need Express server
Auto-scalingManual scaling
Cold startsNone — always on
Request timeoutNo limit
File upload limitConfigurable (any size)
WebSocketsFull Socket.io support
Real-time chatTrue push, no polling
Monthly cost (500 users)$15–25/mo flat

When to use each

✅ Stay on Vercel if:

You want minimal maintenance, deploy by just pushing to GitHub, don't need true WebSockets, and are okay with presigned URL workaround for large files. Good for current stage (1–2 schools, <1,000 users).

⚠️ Switch to Railway/Render when:

You have 3+ schools, 500+ concurrent users, need proper WebSocket live chat (no polling), or large file uploads without browser-to-Supabase workarounds. Migration takes about 2 days of work.

🏢 Use AWS/GCP for Enterprise when:

10,000+ users, SLA requirements, multi-region deployment, compliance requirements (GDPR, NDPR), or dedicated database clusters are needed.

Team recommendation: Stay on Vercel Pro ($20/mo) for now. Implement presigned uploads (removes 4.5MB limit). When you sign on a 3rd school, migrate the API to Railway with Express + Socket.io for proper real-time without polling.
