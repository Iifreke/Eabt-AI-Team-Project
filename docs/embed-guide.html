EABT Widget — Embed Guide

How to add the AI admissions chat widget to any school website.

Step 1 — Get the school slug

Each school has a unique slug in the Supabase schools table. You need this as the schoolId.

SchoolschoolId (slug)
Babcock Universitybabcock
Ahmadu Bello Universityabu
add more rows as schools are onboarded

To add a new school, insert a row into Supabase: INSERT INTO schools (slug, name) VALUES ('oau', 'Obafemi Awolowo University'); and upload its knowledge base documents in the admin panel.

Step 2 — Paste this snippet before </body>

⚠️ Critical: apiUrl MUST always point to the Vercel deployment URL, not window.location.origin. Without it every API call goes to the host site's server (which has no chat API) and the widget will appear to work but never respond. 
<!-- EABT AI Admissions Widget -->
<script>
  window.SchoolBotConfig = {
    schoolId: 'abu',                                        // ← slug from Step 1
    apiUrl:   'https://eabt-ai-team-project.vercel.app',    // ← NEVER change this
    theme: {
      primaryColor: '#1a73e8',                              // ← hex colour to match school brand
      name: 'ABU (Ahmadu Bello University)'                 // ← school display name in widget header
    }
  };
</script>
<script src="https://eabt-ai-team-project.vercel.app/widget.js"></script>
✅ CORS is open to all origins so the widget works on any domain — no extra configuration needed on the host site.

Multi-school selector (optional)

If one page should offer a school picker (like the live demo), use the schools array instead of a single schoolId:

<script>
  window.SchoolBotConfig = {
    schools: [
      { id: 'babcock', name: 'Babcock University' },
      { id: 'abu',     name: 'ABU (Ahmadu Bello University)' }
    ],
    apiUrl: 'https://eabt-ai-team-project.vercel.app',
    theme: { primaryColor: '#1a73e8' }
  };
</script>
<script src="https://eabt-ai-team-project.vercel.app/widget.js"></script>
